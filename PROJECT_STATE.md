# Состояние проекта Sweet Calc

Обновлено: 17.11.2026

## Готово

- Каркас проекта: Vite 5 + React 18 + TypeScript, Tailwind 3, ESLint 9, vitest.
- `vite.config.ts` с `base: '/sweet-calc/'`, `vite-plugin-pwa` (`registerType: 'prompt'`),
  манифест «Sweet Calc» (`display: standalone`, `lang: ru`), генерация иконок через `npm run icons`.
- Слой IndexedDB (схема v1: `stock`, `recipes`, `settings`, `meta`) и репозиторий с CRUD,
  дублированием рецепта, сидом склада (9 позиций упаковки + 104 ингредиента справочника с ценой 0 ₽).
- Ядро расчётов: `calc.ts`, `nutrition.ts`, `scale.ts`, `format.ts` + 46 юнит-тестов (зелёные).
- Справочник КБЖУ на 104 позиции с алиасами и автоподстановкой в форме склада; значения сверены
  скриптом `npm run audit:nutrition`, расхождения объяснены клетчаткой, полиолами и алкоголем.
- Все четыре вкладки: «Калькулятор», «Продукция» (список, просмотр, режим «Замес», форма),
  «Склад» (фильтры, поиск, форма, накладные), «Настройки» (темы, акценты, цены, бэкапы, Gist,
  changelog, демо-рецепт).
- Кроппер 1:1 (`react-easy-crop`) → Canvas 512×512 WebP 0.85 с фоллбэком JPEG.
- 8 SVG-заглушек продукции, иконки PWA (64/192/512, maskable, apple-touch, favicon).
- Тост обновления PWA «Доступна новая версия приложения — Обновить».
- Экспорт/импорт JSON (режимы `replace`/`merge`), GitHub Gist (сохранение/восстановление).
- Workflow `.github/workflows/deploy.yml` для публикации `main` на GitHub Pages.

## Известные проблемы и ограничения

- **UI не проверен в реальном браузере.** В окружении нет headless-браузера: проверены
  типы, линтер, юнит-тесты формул, сборка и HTTP-ответы preview-сервера, но не первый рендер
  React. Ручной smoke-тест (`npm run preview` + сценарии ниже) обязателен, особенно на iOS Safari
  (pinch-зум в кроппере, фиксированная нижняя навигация).
- Перед финальной сборкой исправлены Tailwind-классы `calc()` без пробелов вокруг операторов
  (`pb-[calc(92px_+_env(...))]`) — прежняя запись генерировала невалидный CSS.
- **Агар-агар:** в задании указано значение 900 — это сила геля (г/см²), а не калорийность.
  В справочнике стоит пищевая ценность сухого агар-агара 306 ккал/100 г (USDA) с комментарием
  в коде; пояснение продублировано в README. Меняется одной строкой в `src/data/nutritionPresets.ts`.
- `base`-путь зашит как `/sweet-calc/`; переименование репозитория потребует правки
  `vite.config.ts` и манифеста.
- Токен Gist хранится в открытом виде в IndexedDB устройства (ограничение архитектуры без сервера).
